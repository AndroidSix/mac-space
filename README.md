# 清衡 · MacSpace

创建于 2026-11-11

面向 macOS 的本机磁盘与负载管理工具，使用 Tauri 2、Rust 和 Svelte 5。当前版本 **0.2.0**。默认跟随 macOS 首选语言，支持手动切换简体中文和 English，并同步应用内文案、确认弹窗及原生菜单。

## 使用

- 打开 `release/MacSpace.app`。应用只在本机运行，无需账号。
- 也可从本仓库的 Releases 下载 `.pkg`，安装到 `/Applications/MacSpace.app`。0.2.0 的发布包适用于 Apple Silicon（arm64）、macOS 12 及以上版本。安装器只复制应用，不添加后台服务，也不会自动执行清理。
- **一键智能清理**：在总览或空间清理页点击入口，扫描后弹出勾选列表。默认推荐 pip/npm/Electron 下载缓存与 VS Code 更新缓存；构建缓存、网页缓存、uv 缓存和 Playwright 浏览器默认不选，并逐项解释影响。使用中、读取不完整、几乎为空或未知项目不可选择。点击“清理所选”后串行执行，显示逐项结果和可用空间变化；停止会在当前项完成后跳过剩余项目。单项失败不会中止其余项，失败可能发生在部分文件已删除之后。
- **空间清理**：扫描已识别的缓存目录，查看占用、程序使用状态与清理影响；每次删除都需要确认，不进入废纸篓。
- **磁盘分析**：选择个人文件夹、内置数据卷或其他目录，包括外接磁盘。按目录向下查看，支持取消。此页面只读。
- **运行负载**：查看 CPU、内存、交换空间、进程、系统平均负载、真实温度读数与系统热压力。进程可手动降低调度优先级或发送 SIGTERM；后者可能丢失未保存内容。
- **设置**：语言、采样间隔、节能扫描及文件事件增量更新。窗口不活跃、最小化时暂停周期采样；低电量模式下采样间隔至少 10 秒。

访问受保护的目录时，可能需要在“系统设置 → 隐私与安全性 → 完全磁盘访问权限”中添加 MacSpace，然后重新启动。未读取的路径会计入错误数，不会当作零占用的完整扫描。

## 数据与清理边界

- 只允许清理内置规则中明确列出的缓存；源码、`.git`、聊天记录、编辑器用户数据、SDK 和 Xcode Archives 不在清理名单内。
- “推荐”代表对日常使用影响较小，不保证所有场景完全无感。下载缓存清理后不删除已安装工具，但后续安装可能需要联网；构建缓存会重建，Playwright 浏览器被删除后需要重新安装才能运行相关测试。批量清理会先验证整个选择清单，再逐项重新检查目录与关联进程，不会自动退出程序。
- 删除前重新检查目录身份、所有者和关联进程。原生删除通过目录文件描述符逐级操作，不跟随符号链接，也不跨卷。uv 使用官方清理命令并保留其锁检查；npm 可用时使用官方缓存清理命令。
- 降低优先级是设置 nice 值，不是硬性 CPU 限速；恢复可能需要重启进程。系统、其他用户、清衡自身和祖先进程不提供进程控制操作。
- 扫描读取元数据和已分配数据块，不对文件内容做哈希，不跟随符号链接，不主动下载云端文件内容。硬链接在一次扫描中去重；APFS 克隆共享及快照无法完整归属到各目录，因此估算与实际释放可能不同。
- 温度通过 sysinfo 的 Apple Silicon IOHID 传感器实现读取，并提供 NSProcessInfo 系统热状态；部分系统或硬件可能不提供摄氏度读数，此时显示不可用。传感器最高温不代表 CPU 平均温度。
- 文件变化使用 notify 的 macOS FSEvents 后端。仅在空间清理页活跃时，对变化的缓存目录做合并更新，最多每 30 秒一次；不周期性扫描整盘。重启后对缓存结果做保守失效处理。
- 本地快照位于 `~/Library/Application Support/local.macspace.desktop/snapshot.json`。语言及采样偏好保存在本应用 WebView 的本机存储中。首版只持久化目录汇总，不建立逐文件数据库。

## 开发与验证

需要 Node.js 22.12+、Rust stable 和 Xcode Command Line Tools。此工作区的 Rust 工具链隔离在 `.tools/`，npm 包装脚本会自动使用它，不修改系统 PATH。其他电脑有全局 Rust 时直接使用全局工具链。

```sh
npm ci
npm run tauri -- dev
npm run check
npm test
npm run test:native
npm run tauri -- build --bundles app
npm run package:pkg
```

`package:pkg` 使用 macOS 自带的 `pkgbuild`，优先打包 Tauri 构建目录中的应用，也可传入应用路径：`npm run package:pkg -- /path/to/MacSpace.app`。找不到构建目录时使用 `release/MacSpace.app`。脚本检查版本与应用签名完整性，按实际架构命名安装包，并在 `release/` 生成 `.pkg` 与 SHA256 校验文件。安装位置固定为 `/Applications`，不会因其他目录存在应用副本而改装到那里。源码仓库不包含工具链、依赖、扫描数据及编译产物。

原生测试只删除测试专用临时目录、控制测试自行启动的 sleep 进程，不清理真实缓存或结束用户程序。测试覆盖硬链接去重、符号链接边界、清理根目录保留、进程身份及当前进程保护，以及批量选择校验、失败后继续和项间停止。前端测试检查推荐项排除规则及两种语言的文案与插值字段一致。

界面隔离测试：运行 `npm run dev` 后访问 `http://127.0.0.1:1420/tests/smart-cleanup.html`；可用 `?language=en` 查看英文，`?phase=scanning` 或 `?phase=running` 查看进度。此测试入口只使用 `/test/cache` 虚构记录，不导入 Tauri、不访问真实缓存，也不包含在正式应用构建中。

应用使用 ad-hoc 本机构建签名，未做 Apple Developer ID 签名与公证，PKG 安装器也未签名。在其他 Mac 上安装或启动时，Gatekeeper 可能拦截；确认来源后可按系统提示在“系统设置 → 隐私与安全性”中允许。`release/MacSpace.app` 可独立运行，不依赖 Node、Rust 或源码目录。编译中间产物可以在复制应用后删除。
